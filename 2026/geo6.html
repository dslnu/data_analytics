Spatial Data Analysis

Exploratory Spatial Data Analysis (ESDA)

ESDA augments Tukey’s exploratory data analysis: a large collection of techniques used to “orient yourself” — to find structure inside your dataset.

For geographical problems this usually means asking whether our data displays a geographical pattern.

Whatever the nature of my data: is there a geographical pattern, and are there places where this pattern does not hold?

Choropleth mapping

Overview

Choropleths are geographic maps that display statistical information encoded in a colour palette. They let us display non-geographic attributes on a geographic map.

The word choropleth stems from the root “choro”, meaning region. They represent data at the region level, and are appropriate for areal unit data: each observation combines a value of an attribute with a geometric figure, usually a polygon.

Choropleths derive from an era where technological constraints precluded unclassed maps.

Principles

Three dimensions to think about intentionally

  1. How many groups? Select a number of groups smaller than \(n\) into which all values will be mapped.
  2. Which algorithm? Identify a classification algorithm that executes the mapping following a principle aligned with our interest.
  3. Which colours? Assign a colour to each group so it encodes the information we want to reflect.

In broad terms: the classification scheme defines the number of classes and the assignment rules; a good symbolization conveys value differentiation across classes.

The effectiveness of a choropleth map depends largely on the purpose of the map.

Data classification as a problem

Partition attribute values into mutually exclusive and exhaustive groups. Formally, define class boundaries such that

\[ c_j < y_i \le c_{j+1} \ \forall y_i \in C_{j} \]

where \(y_i\) is the value at location \(i\), \(j\) a class index, and \(c_j\) the lower bound of interval \(j\).

Different classification schemes obtain from their definition of the class boundaries.

Quantitative data classification

The Freedman-Diaconis rule

seaborn.histplot uses matplotlib’s hist under the hood to determine class boundaries. The interval width \(w\) is

\[ w = 2 * IQR * n^{-1/3} \]

where \(IQR\) is the inter-quartile range. Given \(w\), the number of bins is

\[k = \dfrac{(max-min)}{w}\]

The choropleth literature has many alternative algorithms that prioritize different criteria. We compute them with mapclassify, from the PySAL family.

Equal intervals

Same width in value space

A special case of Freedman-Diaconis generalized: split the range into \(k\) equal-length intervals, each of width \(w = \frac{x_{n-1} - x_0}{k}\).

Mean-standard deviation

Distance from the mean, measured in \(s\)

Class boundaries are set at multiples of the standard deviation from the sample mean. A common definition for \(k=5\):

\[c_{0}^u = \bar{x} - 2s, \quad c_{1}^u = \bar{x}-s, \quad c_{2}^u = \bar{x}+s, \quad c_{3}^u = \bar{x}+2s\]

Values beyond \(\pm 2s\) go in the top/bottom class.

Look at the gaps, not the values

Jenks-Caspall breaks

A heuristic, not a deterministic rule

Aims to minimize the sum of absolute deviations around class means.

  1. Start with a prespecified number of classes and an arbitrary initial set of breaks (e.g., quintiles)
  2. Consider moving observations between adjacent classes — the largest value of the lowest quintile into the second, the lowest value of the second into the first
  3. Make the candidate move with the largest reduction in the objective function
  4. Continue until no improving moves remain

Comparing classification schemes

Optimality is relative to an objective

Freedman-Diaconis is “optimal” - but only relative to its objective function: minimizing the difference between the area under the estimated kernel density and that under the theoretical population distribution.

This notion of statistical fit is important, but it is not the only consideration. Also relevant:

  • the spatial distribution of the attribute values
  • the ability of the classifier to convey a sense of that spatial distribution

And these are not necessarily directly related to the statistical distribution.

Comparing classification schemes

Color

A caution before we colour

The spatial units are far from homogeneous in shape and size. This has major impacts on our brain’s pattern recognition: we are drawn to the larger polygons, even when they are not the most relevant.

Yet when we considered the statistical distribution above, each observation was given equal weight.

Thus the spatial distribution is more complicated to evaluate, from both a visual and a statistical perspective.

Color

Three types of numerical attribute

The choice of colour scheme should be based on the type of variable:

  • sequential — continuous data with the origin at one end of the series
  • diverging — continuous data with a meaningful mid-range critical value
  • qualitative — categorical data

Global Spatial Autocorrelation

Global spatial autocorrelation

The concept

The existence of a “functional relationship between what happens at one point in space and what happens elsewhere” - Anselin (1988)

The degree to which similarity in values between observations is related to similarity in locations.

Compare with its relatives:

  • correlation — how values in one variable change as a function of another
  • temporal autocorrelation — the value of a variable now, vs. previous periods
  • spatial autocorrelation — the value of a variable here, vs. the same variable elsewhere

Global spatial autocorrelation

An alternative framing

The degree of information contained in the value of a variable at a given location about the value of that same variable in other locations.

Start from its absence

Spatial randomness: a situation in which the location of an observation gives no information whatsoever about its value. A variable is spatially random if its distribution follows no discernible spatial pattern.

Spatial autocorrelation is the absence of spatial randomness.

Spatial autocorrelation

Two dimensions: sign and scale

Sign:

  • positive (similarity and geographical closeness go hand in hand)
  • negative (similar values located away from each other).

Scale:

  • global (the overall trend that the location of values follows; the degree of clustering)
  • local (deviations from the global trend at much more focused levels).

Why we need statistics at all

At first sight, the map appears to display a fair amount of positive spatial autocorrelation. But humans are very good pattern detectors — life has rewarded pattern recognition since we started as a species.

This extraordinary capability also creates many false positives. And on maps, the shape and size of geometries further distort our perception.

We can guess at the presence of spatial autocorrelation. Determining whether what we see could have come from pure chance is easier said than done.

The spatial lag

Definition

One of the most common and direct applications of spatial weights. In matrix notation:

\[ Y_{sl} = \textbf{W} Y \]

or, individually:

\[ y_{sl-i} = \sum_j w_{ij} y_j \]

Because non-neighbours receive a weight of zero, \(y_{sl-i}\) really captures the product of values and weights for \(i\)’s neighbours.

  • if \(\textbf{W}\) is binary \(\rightarrow\) the sum of the values of \(i\)’s neighbours
  • if \(\textbf{W}\) is row-standardized \(\rightarrow\) a local average: the average value of \(Y\) in the neighbourhood of \(i\)

Conceptually, the spatial lag captures the behaviour of a variable in the immediate surroundings of each location - it is akin to a local smoother.

Continuous case: Moran’s \(I\)

The statistic

\[ I = \dfrac{n}{\sum_i\sum_j w_{ij}} \dfrac{\sum_i\sum_j w_{ij} \, z_i \, z_j}{\sum_i z_i^2} \]

where \(n\) is the number of observations, \(z_i\) the standardized value at \(i\), and \(w_{ij}\) the cell of \(W\) for the pair \((i,j)\).

The Moran Plot

Interpreting p_sim

An empirical p-value: the proportion of realizations in the simulation under spatial randomness that are more extreme than the observed value.

A small enough p-value lets us reject the hypothesis that the map is random — the map displays more spatial pattern than we would expect if values had been randomly allocated to locations.

0.001 is actually the minimum value obtainable given 999 permutations.

If we generated a large number of maps with the same values randomly allocated over space, fewer than 0.1% would display a larger Moran’s \(I\) than the one we observe.

Other global indices

The contiguity ratio: Geary’s \(C\)

\[ C = \dfrac{(n-1)} {2 \sum_i \sum_j w_{ij}} \dfrac{\sum_i \sum_j w_{ij} (y_i - y_{j})^2} {\sum_i (y_i - \bar{y})^2} \]

Both Moran and Geary compare the relationship of \(Y\) within each observation’s local neighbourhood to that over the entire sample. But:

  • Moran’s \(I\) takes cross-products on standardized values
  • Geary’s \(C\) uses differences on the raw values, without standardization

Geary’s \(C\) is computationally more demanding.

geary = esda.geary.Geary(db["Pct_Leave"], w)

Geary's C: 0.408 | p_sim: 0.001

Geary’s \(C\) points in the same direction as Moran’s \(I\): clear spatial autocorrelation.

Other global indices

A statistic of concentration: Getis and Ord’s \(G\)

\[ G(d) = \dfrac{ \sum_i \sum_j w_{ij}(d) \, y_i \, y_j } { \sum_i \sum_j y_i \, y_j } \]

where \(w_{ij}(d)\) is a binary distance band weight.

Conceived for points (hence a distance \(W\)), but applicable to polygons given a binary weights matrix. Designed for positive variables with a natural origin.

An important limitation

\(G\) was proposed as a measure of concentration rather than of spatial autocorrelation. It is well suited to testing to what extent similar values - high or low - tend to co-locate.

It is a statistic of positive spatial autocorrelation only: because \(G\) measures the intensity with which \(Y\) is concentrated, it cannot pick up negative spatial autocorrelation.

Global spatial autocorrelation

Take-aways

Global measures of spatial autocorrelation leverage statistics to do two things:

  1. summarize the spatial distribution of values present in a map
  2. obtain a formal quantification of the departure from randomness
Statistic Built on Detects
Join counts same/opposite category pairs positive & negative (binary data)
Moran’s \(I\) cross-products of standardized values positive & negative
Geary’s \(C\) squared differences of raw values positive & negative
Getis-Ord \(G\) products under a distance band positive only (concentration)

All of them are “whole map” statistics: a single summary for the entire dataset.

Local Spatial Autocorrelation

Local spatial autocorrelation

Why global is not enough

Global measures are “whole map” statistics: a single summary for an entire dataset.

Moran’s \(I\) tells us whether values in our map cluster together (or disperse) overall — but it will not tell us where specific clusters or outliers are.

Local measures focus on the relationship between each observation and its surroundings. They are not summary statistics but scores that let us learn more about the spatial structure in our data.

Local spatial autocorrelation

Where spatial autocorrelation comes from

  • Spillovers - outcomes at one site influence other sites
  • Contagion - outcomes at one site causally influence other sites
  • Heterogeneity - systematic spatial variation
  • Measurement artifacts - e.g., “down-sampling” can create large patches of identical values

Substantive or nuisance, it is a form of non-randomness that complicates statistical analysis.

LISAs

Local Indicators of Spatial Association (Anselin, 1995). Some local statistics are mathematically connected to their global counterparts: the global version can be decomposed into a collection of local ones.

Local Moran’s \(I_i\)

The statistic

\[ I_i = \dfrac{z_i}{m_2} \displaystyle\sum_j w_{ij} z_j \; ; \; m_2 = \dfrac{\sum_i z_i^2}{n} \]

where \(m_2\) is the second moment (variance) of the distribution, \(z_i = y_i - \bar{y}\), and \(w_{ij}\) the spatial weight for the pair \((i,j)\).

The mechanism is similar to the global Moran’s \(I\), but applied to each observation - giving as many statistics as original observations.

What it identifies

Cases in which the value of an observation and the average of its surroundings are either more similar (HH, LL) or more dissimilar (HL, LH) than we would expect from pure chance.

The quadrant classification alone is exhaustive — every point gets a label. LISAs add the crucial question: is the concentration unusually strong?

Exporting LISA results

A mnemonic vocabulary

Positive local spatial autocorrelation:

  • HH \(\rightarrow\) “hot spots” — values at the site and its surroundings are larger than average
  • LL \(\rightarrow\) “cold spots” — significant clusters of low values surrounded by low values

Negative local spatial autocorrelation:

  • LH \(\rightarrow\) “doughnuts” — low value, high surroundings
  • HL \(\rightarrow\) “diamonds in the rough” — high value, low surroundings

The terminology is purely mnemonic, but it helps in remembering the interpretation.

We see many more hotspots/coldspots than doughnuts/diamonds - consistent with the skew in the distribution of local statistics.

    """Create a cluster map from a G_Local object"""
    ec = "0.8"
    # Break observations into significant or not
    sig = g.p_sim < 0.05
    # Plot non-significant clusters
    ns = db.loc[sig == False, "geometry"]
    ns.plot(ax=ax, color="lightgrey", edgecolor=ec, linewidth=0.1)
    # Plot HH clusters
    hh = db.loc[(g.Zs > 0) & (sig == True), "geometry"]
    hh.plot(ax=ax, color="red", edgecolor=ec, linewidth=0.1)
    # Plot LL clusters
    ll = db.loc[(g.Zs < 0) & (sig == True), "geometry"]
    ll.plot(ax=ax, color="blue", edgecolor=ec, linewidth=0.1)
    contextily.add_basemap(

        crs=db.crs,
        source=contextily.providers.Esri.WorldTerrain,
    )
    st = "*" if g.star else ""
    ax.set_title(f"G{st} statistic for Pct of Leave votes", size=15)

Why use \(G_i\) at all?

The results are virtually identical for \(G_i\) and \(G_i^*\), and at first glance similar to the LISA cluster map. So why bother?

They are complementary statistics:

  • local \(I_i\) (on its own) gives an indication of cluster / outlier status
  • local \(G_i\) shows which side of the hotspot / coldspot divide the observation is on

The local Moran’s \(I_i\) cluster map provides both pieces of information - but it can be more challenging to visualize all at once.

It depends on your analytical preferences and the point of the analysis at hand.

Local spatial autocorrelation

Take-aways

Local statistics are one of the most commonly used tools in the geographic data science toolkit — the most common “first brush” geographic statistic for many analyses.

  • Local Moran’s \(I_i\) summarizes the co-variation between observations and their immediate surroundings \(\rightarrow\) cluster and outlier status
  • Getis-Ord local \(G\) compares the sum of values in the area around each site \(\rightarrow\) hotspot / coldspot, but no outliers

Used properly, local statistics provide a powerful way to analyze and visualize the structure of geographic data.

Point Pattern Analysis

Point pattern analysis

Two ways to understand points

1. Fixed objects in space - location is taken as given (exogenous), secondary to the value observed at the point.

Example: the number of cars traversing a road intersection. The location is fixed; the data of interest is the measurement there. Analysis resembles that of polygons and lines.

2. Sites of measurement from an underlying continuous process - the measurement could theoretically take place anywhere, but was only carried out in certain locations.

Example: the length of birds’ wings. Location reflects bird movement and foraging; wing length reflects an ecological process.

We will adopt the second perspective: both the location and the measurement matter.

Point pattern analysis

What is a point pattern?

When points are seen as events that could take place in several locations but only happen in a few of them, a collection of such events is a point pattern. The location of points is one of the key aspects of interest.

A good example is geo-tagged photographs: they could technically happen in many locations, but tend to concentrate in a handful.

Types:

  • unmarked - only the coordinates of where the event occurred
  • marked - more attributes are provided with the location (time, camera model, an “image quality score”)

Point pattern analysis

The questions

Point pattern analysis is concerned with the visualization, description, statistical characterization, and modeling of point patterns:

  • What does the pattern look like?
  • What is the nature of the distribution of points?
  • Is there any structure in the way locations are arranged over space - are events clustered, or dispersed?
  • Why do events occur in those places and not in others?

Point pattern analysis

Process vs. pattern

Process - the underlying mechanism at work that generates the outcome. Abstract; we do not get to see it. It is the how.

Pattern - the result of that process. Often the only trace we can observe, and thus the only input we have to reconstruct it.

Pattern is only a reflection of process. The real challenge is not to characterize the former but to use it to work out the latter.

Kernel density estimation

Escaping the grid

Grids are the spatial equivalent of a histogram: the user decides how many “buckets” and points are counted discretely. Fast, efficient, potentially detailed — but a discretization of an essentially contiguous phenomenon, which may introduce distortions (e.g., the modifiable areal unit problem).

A kernel density estimate (KDE) is an empirical approximation of the probability density function:

  • lay a grid of points over the space of interest
  • place kernel functions on them that count nearby points with a weight based on distance
  • aggregate to generate a global probability surface

The most common kernel is the Gaussian one.

If the hexbin is a “spatial histogram”, centrography is the point pattern equivalent of the mean and standard deviation.

Many indices provide an indication of:

  • how tightly it clusters around its centre

Extent

Five shapes, varying tightness

  • convex hull — the tightest convex shape enclosing the points; never “doubles back”, no divets, valleys or holes; all interior angles below 180°
  • alpha shape (concave hull) — a tighter version of the convex hull
  • minimum bounding rectangle — the tightest axis-aligned rectangle
  • minimum rotated rectangle — allowing diagonals gives a smaller area, but an askew rectangle
  • minimum bounding circle — the smallest enclosing circle; often bigger than the bounding rectangle

To make differences clear we use the photos of the most prolific user in the dataset.

Extent

The rolling-ball intuition

A convex hull is the space left over when rolling a really large ball around the shape — so large its radius is infinite, so the lines are straight.

An alpha shape is the space made from rolling a small ball around the shape. It rolls into the dips and valleys between points. As the ball grows, the alpha shape becomes the convex hull. If alpha gets too small, the ball “slips” through the points, producing more than one hull.

Randomness and clustering

How even is the distribution?

Do points tend to all cluster near one another, or disperse evenly throughout the problem area? This refers to the intensity or dispersion of the pattern overall.

In other words: what is the overall degree of clustering?

Two families of technique:

  1. Quadrat statistics - split the data into small areas (“buckets”) and examine the uniformity of counts across them
  2. Ripley’s functions - measurements of the distance between points in the pattern

A trap: irregular study areas

Quadrat counts are measured on a regular tiling overlaid on a potentially irregular extent. Irregular but random patterns can be mistakenly found “significant”.

One way to reconcile this: think of the quadrat statistic as testing both the uniformity of points and the shape of their extent. Useful sometimes; use with caution.

Ripley’s alphabet of functions

Two quantities

Derived from Ripley’s seminal work on characterizing clustering or co-location:

  • nearest neighbour distances - how far each point is from its closest companion
  • “gaps” in the pattern - how far empty space is from the nearest point

Each function characterizes an aspect of the pattern as we increase the distance range from each point.

Ripley’s \(G\)

Keeps track of the proportion of points for which the nearest neighbour is within a given distance threshold, plotted against increasing distance radii.

  • \(G\) increasing rapidly with distance \(\rightarrow\) clustered
  • \(G\) increasing slowly \(\rightarrow\) dispersed
  • something in between \(\rightarrow\) hard to distinguish from pure chance

Identifying clusters

Clustering vs. clusters

The previous sections characterize whether a pattern is dispersed or clustered - the degree of overall clustering.

But knowing a pattern is clustered does not tell us where the clusters are. For that we need a method able to identify areas of high density of points.

The distinction is exactly analogous to global vs. local spatial autocorrelation.

The difference in technique comes from the unique nature of points: earlier methods take the location of objects as given and study the configuration of values; point pattern methods treat points as events that happen in particular locations but could happen in a much broader set of places.

DBSCAN

Density-Based Spatial Clustering of Applications with Noise

A widely used algorithm from knowledge discovery and machine learning. Its popularity resides in intellectual simplicity and computational tractability.

In some ways a point pattern counterpart of the local statistics - but with a fundamental difference: DBSCAN is not based on an inferential framework, it is a deterministic algorithm. We cannot estimate the degree to which the clusters found are compatible with spatial randomness.

DBSCAN

The definition

A cluster is a concentration of at least m points, each within a distance r of at least another point in the cluster. Each point is classified as:

  • Noise - outside a cluster
  • Core - inside a cluster, with at least m points of the cluster within distance r
  • Border - inside a cluster, with fewer than m points of the cluster within r

Both m and r must be specified by the user - the flexibility and the limitation.

Point pattern analysis

Take-aways

  1. Visualize the locations, overcoming the “cluttering” challenge - hexbin and KDE
  2. Characterize their spatial distribution statistically - central tendency, dispersion, extent; the point pattern counterparts of the mean and standard deviation
  3. Test whether the pattern is clustered or dispersed - quadrat and Ripley’s functions
  4. Locate the clusters themselves - DBSCAN

These techniques answer fundamental questions about point patterns representing widely varied phenomena: from where photographs were taken, to the distribution of bird nests, to the clustering of bike crashes in a city.
