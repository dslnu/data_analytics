Error!

From local

Why?

Version mismatch.

  1. On Kubernetes:
$ kubectl exec deploy/dask1-scheduler -- python -c "import dask, distributed; print('Cluster:', dask.__version__, distributed.__version__)"

Cluster: 2024.1.0 2024.1.0
  1. Local version:
$ uv run python -c "import dask, distributed; print('Cluster:', dask.__version__, distributed.__version__)"

Cluster: 2025.9.1 2025.9.1

From local

Solution

Create values.yaml:

scheduler:
  spec:
    type: LoadBalancer
  image:
    repository: ghcr.io/dask/dask
    tag: 2025.9.1 # or your preferred version

worker:
  image:
    repository: ghcr.io/dask/dask
    tag: 2025.9.1

jupyter:
  image:
    repository: ghcr.io/dask/dask-notebook
    tag: 2025.9.1

From local

Solution

  1. Delete scheduler service (it was edited before when setting LoadBalancer service type):
kubectl delete svc dask1-scheduler
  1. Then upgrade deployment:
helm upgrade dask1 dask/dask -f values.yaml
  1. (OPTIONAL, if no EXTERNAL-IP) Edit again and change type to LoadBalancer.
kubectl edit service dask1-scheduler

From local

Check versions now

kubectl exec deploy/dask1-scheduler -- python -c "import dask, distributed; print('Cluster:', dask.__version__, distributed.__version__)"

Cluster: 2025.9.1 2025.9.1

Now local jupyter should work using your new EXTERNAL-IP!
