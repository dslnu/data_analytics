Where we left off

Bio 3 recap

  • 16S sequences \(\rightarrow\) k-mer feature table \(\rightarrow\) PCoA (unsupervised) and a hand-written Naive Bayes classifier (supervised).
  • Naive Bayes is not a toy: QIIME 2’s default taxonomy classifier (q2-feature-classifier) is scikit-learn’s MultinomialNB on k-mers, and the RDP classifier is Naive Bayes too.

Today

  1. Other classifiers on the same k-mer table: logistic regression, random forest.
  2. Data leakage that is specific to biological sequences.
  3. Convolutional networks on raw (one-hot) DNA: learning motifs instead of counting k-mers.
  4. Protein language models: pretrained embeddings as features.
  5. Where deep learning actually runs in sequencing today.

Classical ML on k-mer tables

The data

Genus classification from short reads

  • Greengenes 97% OTU reference, as in Bio 2–3.
  • Keep sequences annotated to species, in genera that have at least 3 species with \(\geq 8\) sequences each.
  • Truncate to the first 100 bases — roughly the length of a short sequencing read.
  • Label: genus. We also keep the species, which we’ll need later.

def load_species_annotated_reads(read_length=100):
    id_to_taxonomy = {}

        identifier, taxonomy = line.strip().split('\t')

Three classifiers

Same input, different models

  • Multinomial Naive Bayes: the Bio 3 classifier, from the library. Assumes k-mers are independent given the class.
  • Logistic regression: a linear model on k-mer frequencies. Weights k-mers jointly, so correlated k-mers are not double-counted.
  • Random forest: many decision trees on random subsets of samples and features. Captures interactions (“k-mer A and not k-mer B”); the standard choice for microbiome feature table \(\rightarrow\) phenotype (QIIME 2’s q2-sample-classifier).

Evaluation

5-fold stratified cross-validation: each fold keeps the genus proportions of the full data.

Data leakage in sequence data

Sequences are not independent

The i.i.d. assumption

  • Cross-validation assumes samples are independent draws.
  • Sequences are related by evolution: two reads from the same species share most of their k-mers.
  • A random split puts sister sequences on both sides \(\rightarrow\) the test set is partly a copy of the training set.

What we actually want to know

Real samples contain organisms that are not in the reference database. Can the classifier assign the right genus to a read from a species it has never seen?

Grouped cross-validation

GroupKFold

  • Each sample gets a group label; all samples of a group land in the same fold.
  • Group = species \(\rightarrow\) every test species is unseen during training.
  • More generally: cluster sequences by identity (e.g., with MMseqs2 or CD-HIT) and use clusters as groups.
from sklearn.model_selection import GroupKFold

species_cv = GroupKFold(n_splits=5)
species_cv_accuracy = {name: cross_val_score(clf, X, y, cv=species_cv, groups=species).mean()
                       for name, clf in classifiers.items()}

Exercises

  • Change the read length to 150 and 500 bases. How do the two accuracies, and the gap between them, change?

Leakage: takeaways

Rules of thumb

  • The split must mimic the deployment question: new reads from known species? new species? new environments?
  • Homology between train and test inflates accuracy. In protein ML (function, structure, localization) the standard is to cluster at e.g. 30–50% identity and split by cluster.
  • Report which split you used. A number without it is not interpretable.

Deep learning I: convolutional networks on DNA

From k-mers to learned features

Why

  • A k-mer table fixes the features in advance: exact words of length \(k\), position discarded.
  • Biological signals are often fuzzy motifs: e.g., a transcription-factor binding site tolerates substitutions at some positions but not others.
  • A position weight matrix (PWM) describes such a motif: for each position, a probability per base.

Idea

  • Encode DNA as a one-hot matrix: 4 channels (A, C, G, T) \(\times\) length.
  • A 1D convolution filter of width \(w\) is a \(4 \times w\) weight matrix slid along the sequence — it is a PWM-like motif scanner, and its weights are learned.
  • DeepBind (Alipanahi et al., 2015) and Basset (Kelley et al., 2016) introduced this to genomics.

A synthetic task

Plant a motif

  • 4000 random sequences of length 100.
  • In half of them, insert one instance of a motif sampled from a known PWM, at a random position.
  • Task: does the sequence contain the motif? We know the answer, so we can check what the network learns.
rng = np.random.default_rng(0)
ALPHABET = 'ACGT'

# rows: motif positions; columns: probability of A, C, G, T
motif_pwm = np.array([[.90, .04, .03, .03],
                      [.03, .03, .04, .90],
                      [.05, .05, .85, .05],
                      [.90, .04, .03, .03],
                      [.03, .90, .04, .03],
                      [.03, .03, .04, .90],
                      [.05, .05, .05, .85],
                      [.03, .04, .90, .03]])
motif_consensus = ''.join(ALPHABET[i] for i in motif_pwm.argmax(axis=1))

def simulate_sequences(n, length=100):
    sequences = rng.integers(0, 4, size=(n, length))
    labels = np.arange(n) % 2
    for seq, label in zip(sequences, labels):
        if label:
            start = rng.integers(0, length - len(motif_pwm))
            seq[start:start + len(motif_pwm)] = [rng.choice(4, p=row) for row in motif_pwm]
    return sequences, labels

int_sequences, motif_labels = simulate_sequences(4000)
print('motif consensus:', motif_consensus)
print(''.join(ALPHABET[i] for i in int_sequences[1]))

One-hot encoding

import torch

def one_hot(int_sequences):
    # (n, length) integers -> (n, 4, length) floats: channels first, as Conv1d expects
    return torch.tensor(np.eye(4, dtype=np.float32)[int_sequences].transpose(0, 2, 1))

X_dna = one_hot(int_sequences)
y_dna = torch.tensor(motif_labels, dtype=torch.float32)

train_idx, test_idx = np.arange(3000), np.arange(3000, 4000)

A minimal CNN

Architecture

  • Conv1d(4, 8, kernel_size=11): 8 learned motif detectors, each 11 bases wide.
  • ReLU: keep only positive matches.
  • AdaptiveMaxPool1d(1): the best match anywhere in the sequence — position doesn’t matter.
  • Linear(8, 1): combine the 8 detector scores into one logit.
import torch.nn as nn

torch.manual_seed(0)
cnn = nn.Sequential(
    nn.Conv1d(in_channels=4, out_channels=8, kernel_size=11, padding='same'),
    nn.ReLU(),
    nn.AdaptiveMaxPool1d(1),
    nn.Flatten(),
    nn.Linear(8, 1),
)
sum(p.numel() for p in cnn.parameters())

Training

def accuracy(model, X, y):
    with torch.no_grad():
        return ((model(X).squeeze(1) > 0).float() == y).float().mean().item()

optimizer = torch.optim.Adam(cnn.parameters(), lr=1e-2)
X_train, y_train = X_dna[train_idx], y_dna[train_idx]

for epoch in range(15):
    permutation = torch.randperm(len(train_idx))
    for batch in permutation.split(100):
        logits = cnn(X_train[batch]).squeeze(1)
        loss = nn.functional.binary_cross_entropy_with_logits(logits, y_train[batch])
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    if epoch % 5 == 4:
        print(f'epoch {epoch + 1}: test accuracy {accuracy(cnn, X_dna[test_idx], y_dna[test_idx]):.3f}')

Why the gap

  • Small \(k\): words too short to be specific; they occur by chance in every random sequence.
  • Large \(k\): the motif is sampled from a PWM, so only \(0.9^8 \approx 43\%\) of instances are the exact consensus; the rest are scattered over many different, rare 8-mers.
  • The convolution scores similarity to a motif, not exact matches.

CNNs in genomics

Real tasks of this shape

  • TF binding from ChIP-seq peaks (DeepBind), chromatin accessibility from ATAC/DNase-seq (Basset), splicing (SpliceAI).
  • Deeper stacks: dilated convolutions and attention extend the reach to \(10^5\)–\(10^6\) bases (Enformer, AlphaGenome).
  • Interpretation: filter logos, in silico mutagenesis, attribution methods (DeepLIFT, TF-MoDISco) recover known motifs.

Deep learning II: protein language models

Pretrained embeddings

Idea

  • Train a transformer on millions of unlabeled protein sequences with a masked-token objective: predict hidden amino acids from context.
  • To do that well, it must learn conservation, structure, function — without labels.
  • Use the network’s internal representation as a feature vector for any downstream task: an embedding.
  • ESM-2 (Lin et al., 2023): 8M to 15B parameters. The 8M model runs on a laptop CPU.

Same pattern as text

k-mer counts \(\approx\) bag-of-words; protein LM embeddings \(\approx\) sentence embeddings. Then: logistic regression on top.

A task: subcellular localization

Data from UniProt

  • Reviewed human proteins (Swiss-Prot), 80–400 amino acids.
  • Four locations, each protein annotated with exactly one of them.

Embedding with ESM-2

Mean-pooled last layer

  • The model outputs a 320-dimensional vector per residue.
  • Average over residues \(\rightarrow\) one 320-dimensional vector per protein.
import esm

esm_model, esm_alphabet = esm.pretrained.esm2_t6_8M_UR50D()
esm_model.eval()
batch_converter = esm_alphabet.get_batch_converter()

def embed(sequences, batch_size=32):
    embeddings = []
    with torch.no_grad():
        for i in range(0, len(sequences), batch_size):
            batch = sequences[i:i + batch_size]
            _, _, tokens = batch_converter([(str(j), s) for j, s in enumerate(batch)])
            residues = esm_model(tokens, repr_layers=[6])['representations'][6]
            # position 0 is the start token; padding follows the sequence
            embeddings += [residues[j, 1:len(s) + 1].mean(dim=0).numpy() for j, s in enumerate(batch)]
    return np.array(embeddings)

protein_embeddings = embed(protein_seqs)

Language models for DNA

Same idea, different alphabet

  • DNABERT-2, Nucleotide Transformer: BERT-style models on genomes of many species.
  • Evo 2 (Arc Institute, 2025): trained on ~9 trillion bases across all domains of life; long context (up to 1 Mb).
  • Harder than proteins: most DNA is non-coding, signals are sparse, and evaluations are still being standardized. On many tasks, a well-tuned CNN remains a strong baseline.

Landscape

Where deep learning runs in sequencing today

Producing the data

  • Basecalling: Oxford Nanopore’s Dorado turns raw electrical current into bases with neural networks. Every nanopore read you analyze is a model output.
  • Variant calling: DeepVariant (Poplin et al., 2018) renders read pileups as images and classifies genotypes with a CNN.

Interpreting the data

  • Structure: AlphaFold 2/3 (Jumper et al., 2021; Abramson et al., 2024); ESMFold builds structure directly on ESM-2.
  • Sequence \(\rightarrow\) function: Enformer (Avsec et al., 2021), AlphaGenome (2025) predict expression and chromatin tracks from DNA; SpliceAI predicts splicing.
  • Single-cell: scVI (Lopez et al., 2018) — a variational autoencoder for count matrices, used for batch integration (see the single-cell part of the reading notes).

And where it doesn’t (yet)

  • Taxonomy of amplicons: Naive Bayes / k-mer methods remain the default; deep models have not displaced them.
  • Metagenomic read classification: Kraken 2 (exact k-mer matching + lowest common ancestor) dominates on speed.
  • Small labeled datasets: random forests and regularized linear models are hard to beat.

Summary

Choosing a method

  • Start with the simplest model on sensible features (k-mers + Naive Bayes / logistic regression / random forest).
  • Get the split right before comparing models: group by species, cluster, or family.
  • Move to a CNN when the signal is a fuzzy, position-free motif and you have thousands of labeled sequences.
  • Use pretrained embeddings when labels are scarce but the sequences resemble what the model was trained on.
